# Lightbase

Inventory management and current account tracking system ported to Vite + React SPA.

## Features
- **Products (Ürünler)**: Full CRUD, stock tracking, categories, Excel (.xlsx) and CSV export, search and sort.
- **Current Accounts (Cari Hesaplar)**: Account management with balances and export.
- **Catransactions (Cari Hareketler)**: Financial transaction entries with account association.
- **Product Transactions (Ürün Hareketleri)**: Stock movement (IN/OUT) with quantity, price, and product association.
- **Dual Culture Support**: English and Turkish (Türkçe).
- **Theme**: Light and Dark mode toggle.
- **Data Persistence**: In-memory with LocalStorage persistence, pre-seeded with original records.

## Development
```bash
npm install
npm run dev
```
Dev server runs on port 3000 at `0.0.0.0`.
